# 🏆 大会管理ボット 使い方ガイド

Discord 内でトーナメント・リーグ戦を完結させるボットです。
参加登録から試合結果報告・次ラウンド進行まで、すべてボタン操作で行えます。

---

## 📌 対応している大会形式

| 形式 | 概要 |
|------|------|
| 🗡 シングルエリミネーション | 負けたら脱落。最大64名。Bye処理自動 |
| 📊 リーグ戦（総当たり） | 全員と1回ずつ対戦。勝ち点で順位決定 |
| 🎲 スイスドロー | 同勝利数同士でマッチング。ラウンド数を事前設定 |

> 個人戦・団体戦どちらにも対応しています。

---

## 🚀 主催者の手順

### 1. 大会を作成する
```
/tnm create
```
モーダルが開くので以下を設定します：

- **大会名**
- **先取数**（1先〜5先）
- **1試合のラウンド数**
- **ハンデルール**（任意）
- **最大参加人数**（任意）
- **団体戦の有無**

送信すると **告知メッセージが自動投稿** されます。

### 2. 参加者を集める

告知メッセージのボタンから参加者が自己登録します。
主催者が代わりに登録したい場合は `/tnm view` の管理パネル → **👤 代理エントリー**。

### 3. 受付を締め切る（任意）

`/tnm view` → 管理パネル → **🔒 受付終了**
※ 再開したい場合は **🔓 受付を再開** で戻せます。

### 4. 大会をスタートする

`/tnm view` → 管理パネル → **▶ 大会スタート**

- ブラケット（またはリーグ表）が生成される
- 各試合のメッセージが自動投稿される（マッチコード・VC・ハンデ付き）
- Bye（不戦勝）は自動処理される

### 5. 試合を進行する

- 試合終了後、参加者が「**〇〇の勝利 ✅**」ボタンを押す
- 勝者が自動で次ラウンドへ進む
- 全試合終了 → **優勝者アナウンスが自動投稿**

## 🎮 参加者の手順

### 個人戦

1. 告知メッセージの「**参加する 🎮**」ボタンを押す
2. **ランク**をドロップダウンから選択（闘神グラマス〜アイアン1 の21段階 / 未指定・ランダムも可）
3. **使用キャラ名**をテキスト入力して送信
4. ✅ 「参加者一覧 📋」で登録確認

> - 開始前なら「**✏️ エントリー編集**」でランク・キャラを変更できます
> - 開始前なら「**🚪 参加取り消し**」でキャンセルできます

### 団体戦

**チーム作成制の場合**
- 先に入る人が「**チームを作る ➕**」でチームを作成
- メンバーは「**チームに参加 📋**」でチームを選んで参加

**振り分け制の場合**
- 「**参加登録 🎮**」で登録後、主催者がランダム配分する

## ⚖️ ハンデルールについて

ランク差に応じて**強い側のみ先取数が上乗せ**されます。

**設定形式:** `ランク差:落とし数, ランク差:落とし数, ...`

**例:** `3:1,7:2`
- ランク差 3〜6 → 強い側に **1ラウンド落とし**
- ランク差 7以上 → 強い側に **2ラウンド落とし**

**先取2・ハンデ1Rの場合:**
- 弱い側は通常通り **2勝** で勝利
- 強い側は **3勝** が必要

ランク差はランクインデックスの差（闘神グラマス=0 〜 アイアン1=20）で計算。
設定なしの場合はハンデなしの大会になります。

## 🛠 主催者向けコマンド一覧

| コマンド | 説明 |
|---------|------|
| `/tnm create` | 大会を新規作成 |
| `/tnm view` | 大会の状況確認 + 管理パネル |
| `/tnm list` | サーバー内の大会一覧 |
| `/tnm help` | ボット内でガイドを表示 |

### 管理パネルのボタン

| ボタン | タイミング | 説明 |
|--------|----------|------|
| ▶ 大会スタート | 受付中 | ブラケット生成・試合開始 |
| 🔒 受付終了 | 受付中 | 参加締め切り |
| 🔓 受付を再開 | 受付終了後 | 締め切りを取り消して再開 |
| 👤 代理エントリー | 受付中 | 主催者が代わりに参加者を追加 |
| ✏️ 結果修正 | 進行中 | 誤報告を正しい勝者に修正 |
| 👥 チーム設定 | 受付中（団体戦） | チーム名を変更 |
| 🎲 振り分け | 受付中（団体戦） | 参加者をランダムにチーム配分 |
| 🗑 大会削除 | いつでも | 大会と全データを完全削除 |

## ❓ よくある質問

**Q. 誰でも勝利ボタンを押せるの？**
A. はい、誰でも押せます。不正報告があった場合は試合メッセージに表示される **マッチコード** を主催者に伝えてください。主催者が「✏️ 結果修正」で修正できます。

**Q. 参加人数が2のべき乗でなくてもいい？**
A. シングルエリミネーションの場合は自動的に Bye（不戦勝）で埋めます。参加者の中から抽選で不戦勝者が決まります。

**Q. VC（ボイスチャンネル）は自動で作られる？**
A. 自動作成はしません。大会スタート前にサーバー内に対戦用 VC を用意しておくと、試合メッセージに自動割り当てされます。

**Q. 大会をやり直したい場合は？**
A. 管理パネルの「🗑 大会削除」で削除後、`/tnm create` で再作成してください。

## 技ごとの対処（ガード後）
| カイの技 | 状況 | 対処 |
|---|---|---|
| スタンエッジ | ジャンプガード | ガードした位置で変わる（地上に近いほど有利）が、基本的にカイ側が不利。届くならボタンを押す（反撃が確定することもある） |
| スタンエッジ | 地上ガード | カイ側が不利なのでボタンを押す |
| スタンディッパー | ガード | 反撃が確定。その場からでいいので **Sからの最大コンボ** |
| ダイヤエクラ | ガード | カイ側が不利フレームなのでボタンを押す |
| フードゥルアルク | 立ちガード（こちら+2） | 発生の早いボタンを押す（下記参照） |
| フードゥルアルク | しゃがみガード（こちら-1） | 押さない（下記参照） |
| ヴェイパースラスト（S版） | ガード | カイは非カウンター状態。**ダッシュ近S** か **ダスト最大溜め** からの簡単なコンボでいいので最大反撃 |
| ヴェイパースラスト（HS版） | ガード | 実戦ではカイのコンボミス時に起きる。非カウンター状態ではないので、**近S** からできる限りの最大を決める |
| ライドザライトニング | ガード | ヴェイパースラスト（S版）と同じ |
| セイクリッドエッジ | ガード | カイ側が有利。ボタンは押さず、ガード・昇竜・ファジージャンプで凌ぐ |
| ドラゴンインストール | 発動時 | カイ側が有利。ボタンは押さず、ガード・昇竜・ファジージャンプで凌ぐ |

> 昇竜などの反撃ポイントでは、できる限りの最大反撃を取ること。取らないと、相手は気軽に撃ってくる。

## フードゥルアルクはガード方法で行動を変える
こちらから見て **立ちガード時 +2、しゃがみガード時 -1**。

### 立ちガードしたとき
- 発生の早いボタンを押す（その後の行動まで入れ込みでOK）
- 投げが届く密着なら、**投げ** られるのが一番いい（難しければ無理しない）

### しゃがみガードしたとき
- おとなしくガード、もしくは昇竜
- できるならファジージャンプでもいい

## 立ち回り
- スタンエッジはガードしながら飛び越える
- 立ちHの位置まで頑張って距離を詰めたい
- 相手の飛びは6Pで叩き落とす。ダッシュで近づいてきたら2Pで止める

## 帯電状態
細かく変わるので、いったん割愛。

## 補足
- カイの昇竜は若干遅いので、詐欺飛びの検証にはソルやブリジットなど最速9Fの昇竜持ちキャラを使うとよさそう

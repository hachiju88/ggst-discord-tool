ブリジットで2Kを当てたいと相談したところ、「まず立ち回りを強くするのが一番」と教わった内容のまとめ。

## 基本姿勢
- **立ちHが届くか届かないかの辺り** でうろうろして、相手を観察する（待ち）
- 相手の空振りを誘発する

## 攻め方・技を振るタイミング
| 相手の行動 | こちらの行動 |
|---|---|
| 空振りが見えた | 技を振る |
| 技の射程に入った | とりあえず届く技を振る |
| 技を振った | 硬直を狙って差し返し |
| ダッシュが見えた | 2Kを置く（2Sでも可） |
| ジャンプが見えた | 6P（前P）を振る |
| 何もしてこない | ダッシュ2Kを差す（2Sでも可） |
| リーチの長い技を振りそう | 読んで空中ダッシュで近づく |

## 守り方
- 我慢してガードで凌ぐ
- 相手のコンボミスが見えたら反撃
- 有利フレームを覚えていれば、ガード後に暴れる

## 注意点
- **差しに行くときは絶対に技を空振りしない**
- 置き技を空振りするのは別に良い

## メモ（対ブリジット）
- ブリジット相手に2Kを当てるのは難しいらしい（リーチの長いキャラ全般も多分そう）
- 相手ブリジットの立ちH → H は、直ガに成功するとこちらが有利になるらしい

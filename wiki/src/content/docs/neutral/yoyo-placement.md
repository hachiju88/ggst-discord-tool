キャラ間の距離が **端と端** くらいある前提で投げるように意識する。

| 設置 | 使い方 |
|---|---|
| 波動S版 | 単品、もしくはHSとセットで |
| 波動HS版 | 飛びが多い相手に投げる |
| 竜巻S版 | 単品で投げて様子見。返ってくるタイミングに合わせて攻める |
| 竜巻HS版 | コンボ以外では使っていない |
| 空中・波動S版 | 端から逃げるときだけたまに使う |
| 空中・波動HS版 | 一番気軽に投げられて、意外と刺さる |
| 空中・竜巻S版 | 使っていない |
| 空中・竜巻HS版 | 使っていない |

## 補足
- 立ちHS > 派生HS > 竜巻Sヨーヨー設置 で〆ると、ヨーヨーがあるだけで相手は攻めにくい
- 5HS（ガードされた）> 竜巻S設置 > 5HS で安全に設置できる（→「画面中央の連携3種」）
